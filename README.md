# AI自動運用シミュレーター（Version 1）

教育・実験用のローカルWebアプリです。初期資金は仮想1,000,000円。証券会社のAPI、口座、注文機能は含みません。

## 起動

Python 3.10以降が必要です。追加ライブラリは使いません。

- Windows: `start_windows.bat` をダブルクリック
- Mac/Linux: `python3 server.py` を実行
- ブラウザーで `http://127.0.0.1:8765` を開く
- スマホで同じWi-Fiから使う場合（PCが必要）は、後述の「スマホから同一Wi-Fiで利用」を参照
- PCなしでiPhone単体だけで使いたい場合は、後述の「PCなしでiPhone単体で利用」を参照

最初はAI APIキーなしで起動できます。この場合は「5日・20日移動平均と直近5営業日の変化」を使う単純なルール判定です。LLMによる分析ではありません。判断材料は価格だけで、ニュースや決算等は分析しません。

## 市場データと対象

Yahoo Finance Chartの公開データをサーバーから取得します。データ取得に失敗した銘柄は取引せず、対象から除外します。価格はリアルタイム保証ではありません。データは同じ銘柄ごとに15分キャッシュされます。外部データ提供元の利用条件、遅延、提供継続性を確認してから利用してください。

初期対象はAAPL、MSFT、NVDA、SPY、QQQ、7203.T、6758.T、1306.Tです。指数は比較用で売買しません。

## 保存

`papertrade.sqlite3` に現金、設定、判断、取引履歴、資産記録を保存します。サーバーを止めてもデータは残ります。このフォルダをバックアップしてください。ブラウザーのlocalStorageには取引データを置きません。

## 安全設計

サーバーは初期設定で `127.0.0.1` のみで待ち受けます。コードに証券会社APIや発注先はありません。取引記録にはすべて仮想注文と理由が保存されます。市場データのテキストをAI命令として使う処理もありません。

## 仕様の境界

Version 1は市場価格と出来高、価格ルール分析、リスク上限、仮想取引、履歴、資産表示を実装します。企業ニュース・決算、経済指標・金利、ベンチマーク比較、AI成績分析（勝率やドローダウン）、LLM API連携・料金計測は未実装です。画面でAI API料金は0円と表示していますが、それはAI APIを呼び出していないためです。無料データ提供の継続や利用条件は保証されません。

## スマホから同一Wi-Fiで利用

LAN公開は安全上初期設定で無効です（従来通り `127.0.0.1` のみで待ち受け）。自分の端末だけで使うのが基本です。

スマホからも使いたい場合は、PCとスマホを**同じ信頼できる家庭内Wi-Fi**に接続したうえで、以下のいずれかでLAN公開モードを有効にして起動してください。他人がアクセスできないネットワークであることを確認し、インターネットには公開しないでください（ルーターのポート開放・外部公開設定は行わないこと）。

- Windows: `start_lan_windows.bat` をダブルクリック
- Mac/Linux: `start_lan_mac_linux.command` を実行（初回は `chmod +x start_lan_mac_linux.command` が必要な場合があります）
- 手動の場合: 環境変数 `ALLOW_LAN=1` を設定してから `python3 server.py` を実行

起動すると、ターミナル/コマンドプロンプトに `http://（PCのIPアドレス）:8765` の形式でURLが表示されます。そのURLをスマホのブラウザーで開いてください（PC自身でも同じURLでアクセスできます）。

使い終わったらLAN公開モードは終了し、通常は `python3 server.py`（`start_windows.bat`）で自分の端末のみに戻すことをおすすめします。ファイアウォールの確認画面が出た場合は「プライベートネットワーク」のみ許可してください。

## PCなしでiPhone単体で利用

**重要な注意点：** iOSはバックグラウンドでのプログラム実行を強く制限しているため、
「iPhoneのアプリでサーバーを起動し、Safariで別に開く」という方法は、
Safariに切り替えた瞬間にサーバー側が一時停止し、安定して動きません。
そのため以下の方法では、有料アプリ「Pythonista 3」（App Store、買い切り課金）を使い、
**サーバーと画面表示を同じアプリの中で完結させる**ことで、この制限を回避しています。
PCもWi-Fi共有も不要ですが、Pythonista 3を完全に終了する（タスクを閉じる）と
サーバーも止まる点はご了承ください（再度開いて実行すれば再開できます）。

1. App Storeで「Pythonista 3」（Ole Zorn作、買い切り課金）を購入・インストール
2. このフォルダ一式（`server.py` `index.html` `api_pricing.json` `pythonista_iphone.py` など）を
   Pythonistaのスクリプトフォルダにコピーする（Filesアプリやメール添付・AirDrop・iCloud Driveなどで
   zipを共有し、Pythonista側で展開する方法が簡単です）
3. Pythonista内で `pythonista_iphone.py` を開き、右上の再生ボタンで実行
4. アプリ内に仮想トレード画面がそのまま表示されます。使い方はPC版と同じです
5. OpenAI APIを使いたい場合は、環境変数の代わりに同じフォルダに `openai_key.txt` を作り、
   1行目にAPIキーだけを書いてください（`.env`より簡単に読み込めるようserver.py側で対応済みです）
6. データ（`papertrade.sqlite3`）はPythonista内のこのフォルダに保存されます。
   Pythonistaのアプリ削除やiOSの再インストールで消える可能性があるため、
   Filesアプリ経由で定期的にiCloud等へコピーしてバックアップしてください

なお、この方法はiPhone単体でPCから独立して動きますが、Pythonista 3は有料アプリであることと、
画面ロックや長時間のバックグラウンド化でサーバーが停止する可能性がある点は、
iOSの仕様上の制約としてご了承ください。「PCを起動している間だけスマホからも見たい」だけなら、
前述の「スマホから同一Wi-Fiで利用」の方法（無料・PCが必要）の方がシンプルです。

## クラウドで常時稼働させる（PC・iPhoneの電源不要、無料枠）

外出先からいつでも見たい場合、Renderという会社の無料の「Web Service」枠にこのアプリをデプロイする方法があります。PCやiPhoneの電源を入れておく必要はありません。

**無料枠の制約（重要）**
- 15分アクセスがないと自動的にスリープし、次のアクセス時に再起動で30〜60秒ほど待たされます（無料枠の仕様）
- 無料枠にはディスクの永続化保証がありません。スリープ→再開では`papertrade.sqlite3`のデータは残りますが、**再デプロイ（コード更新）をするとデータが消えます**。下記の`/api/backup`で時々バックアップしてください
- 完全にインターネットに公開されるため、下記のパスワード設定は必須です

**手順**
1. GitHubの無料アカウントを作成し、新しいリポジトリを作成。このフォルダの中身（`server.py` `index.html` `api_pricing.json` `requirements.txt` `render.yaml` など）をGitHubのWeb画面から「Add file → Upload files」でアップロード
2. [Render](https://render.com)の無料アカウントを作成し、GitHubアカウントと連携
3. Renderのダッシュボードで「New +」→「Blueprint」を選び、手順1のリポジトリを選択（`render.yaml`を自動で読み込みます）
4. 環境変数の入力を求められるので、`APP_PASSWORD`に自分だけが知るパスワードを設定（`OPENAI_API_KEY`は使う場合のみ設定）
5. デプロイが完了すると `https://（サービス名）.onrender.com` のURLが発行されます。スマホのブラウザーでそのURLを開き、ユーザー名は何でもよいので、パスワード欄に`APP_PASSWORD`で設定した値を入力してください
6. 定期的に `https://（サービス名）.onrender.com/api/backup` にアクセスすると、その時点の`papertrade.sqlite3`をダウンロードできます。コード更新（再デプロイ）の前には必ずこれでバックアップしてください

このモードでは`server.py`がRenderの`PORT`環境変数を自動検出し、`0.0.0.0`で待ち受けます（クラウド常時稼働モード）。`APP_PASSWORD`を設定しないと誰でもアクセス・仮想取引ができてしまうため、必ず設定してください。

## 任意のOpenAI API分析

`OPENAI_API_KEY` 環境変数を設定すると、1銘柄あたり最新データの組み合わせを1時間キャッシュしてOpenAI APIへ分析を依頼します。キーがない場合は追加料金なしのローカル価格ルールへ自動で切り替わります。APIの料金はChatGPT Plusとは別です。使う場合は支出上限を確認し、アカウント利用条件と保護者の同意も確認してください。概算レートは `api_pricing.json` に分離してあります。推定額はその設定値で計算し、実請求額とは異なることがあります。

現在値の参照先（OpenAI公式）: https://developers.openai.com/api/docs/pricing
